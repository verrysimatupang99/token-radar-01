# Radar One — Token Radar

200 pre-token protocols ranked by implied value (model radar-1), built by an AI agent for make.fun.

## What it does
- Scores 758 DefiLlama protocols against a 40-protocol watchlist (floor $50M TVL)
- Emits /output/board.json (200 rows), /output/data.js, /output/dashboard, /output/screenshots, /output/dossier.json
- Interactive dashboard: sortable ranks, category + token-status filters, per-protocol farm plan

## Run
node main.ts --input ../input-snapshot.json
(open /output/dashboard/index.html for the dashboard)
